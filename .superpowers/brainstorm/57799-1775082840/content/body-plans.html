Body Plan Base Geometry

Each body plan defines a skeleton of boxes/spheres. DNA genes then scale, color, and add appendages. Which approach for the base shapes?

A

Box-only (match current style)

All body parts are stretched BoxGeometry — same blocky aesthetic as current creatures. Head = small box, body = large box, legs = thin boxes. Simple, fast, consistent with existing look.

B

Box + Sphere hybrid

Body = box, head = sphere, joints = small spheres. Slightly more organic feel while keeping the low-poly voxel aesthetic. Eyes and joints feel rounder.

C

Segmented boxes (current giant style)

Body built from multiple connected box segments — like the current Wyrm/Titan builds. More visual detail but more draw calls per creature. Best for larger creatures, might be too heavy for small ones.
